OpenCV 灯条识别入门演示
这是一个简单的灯条图像处理项目，主要演示如何使用 OpenCV，从图像中筛选出红色或蓝色灯条，适合初学者了解基础的图像处理流程。
主要内容
- 红蓝识别切换：根据需要，选择识别红色灯条或蓝色灯条。
- 高斯模糊：减小图像中细小噪点的影响，让后续处理更加稳定。
- Mask 掩膜图：将符合颜色条件的区域标为白色，其余区域标为黑色，方便观察筛选结果。
简单易懂的知识点
1. 图像是由像素组成的
可以把一张图像理解为许多小色块拼起来的画面，每一个小色块就是一个像素。
彩色图像中的每个像素通常包含三个颜色通道。OpenCV 默认使用 BGR 顺序，也就是蓝色、绿色、红色。
2. 如何区分红色和蓝色
基本思路是比较颜色，或者设置一个允许的颜色范围，把符合条件的像素筛选出来。
例如，红色区域通常具有较明显的红色分量，蓝色区域通常具有较明显的蓝色分量。不过，亮度、反光和环境光都会影响识别效果，因此需要根据实际画面调整条件。
3. 高斯模糊有什么用
高斯模糊会把附近像素的颜色进行加权平均，让画面变得稍微平滑一些，从而减小部分噪点的影响。
可以理解为：先让画面中的细碎干扰减少，再进行筛选。
模糊程度也不是越大越好，过度模糊可能让灯条的边缘变得不清楚。
4. Mask 图是什么
Mask，也叫掩膜，可以理解成一张“筛选结果图”。
- 白色区域：符合筛选条件，需要保留。
- 黑色区域：不符合筛选条件，暂时忽略。
需要注意：白色区域只是符合颜色条件的候选区域，不一定全部都是灯条，还可能包含背景中颜色相近的物体。
5. 什么是阈值
阈值就是用来判断“是否符合条件”的分界线。
例如，设置一个颜色范围后，范围内的像素会被选中，范围外的像素会被排除。条件太宽，容易选中背景；条件太严，又可能漏掉灯条。
基本处理流程
读取图像 → 高斯模糊 → 根据目标颜色进行筛选 → 生成 Mask 图 → 查看识别效果
通过这个演示，可以初步理解颜色筛选、高斯模糊和掩膜的作用，为后续学习轮廓提取、灯条定位等内容打下基础
